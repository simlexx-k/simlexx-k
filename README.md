I’m a developer based in Nairobi, Kenya. My work at A3S Labs spans web products, applied machine learning, and real-time simulation.

## Selected projects

- **[The Torque](https://github.com/simlexx-k/the-torque)** turns public vehicle posts on X into searchable listings and records where each extracted detail came from.
- **[RotorFrontier](https://github.com/simlexx-k/rotorfrontier)** is a browser-based helicopter simulator with real Nairobi terrain, an optional flight assist, and two-player co-op over WebRTC.
- **[AidLens](https://github.com/simlexx-k/AidLens)** makes development-program evaluation reports searchable. It uses PostgreSQL full-text search and keeps track of the original sources.
- **[Maize Edge AI](https://github.com/simlexx-k/maize-edge-ai)** studies how well lightweight maize disease classifiers trained on controlled images hold up on field photos.
